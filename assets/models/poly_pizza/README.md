# 32 个科技节点的 Poly Pizza 模型

当前 tech_tree.json 中的 **32/32 个节点**各有一个不同模型，共 **8.72 MiB**。格式均为 **GLB / glTF 2.0**，几何与纹理内嵌，无外部依赖。

- 模型文件按节点 ID 命名，例如 `astronomy_nav.glb`、`molecular_biology.glb`。
- [manifest.json](manifest.json)：节点名称、Godot 资源路径、作者、原授权、来源网址、SHA-256、大小、网格、动画和对应理由。
- [CREDITS.md](CREDITS.md)：全部模型的作者、来源和署名文本。
- [licenses/CC-BY-3.0.txt](licenses/CC-BY-3.0.txt) 与 [licenses/CC0-1.0.txt](licenses/CC0-1.0.txt)：官方许可原文。

模型是节点的视觉代表；抽象理论使用实物或符号表达，具体对应理由如下。部分器具采用现代造型，不作为该历史时期仪器的精确复原。

## 在 Godot 中使用

可在文件系统面板直接预览或拖入 GLB；代码中可读取 manifest.json 的 resource_path，以节点 ID 查找对应 PackedScene。实例化时应按节点显示范围设置缩放与居中；原始模型的单位、朝向、尺寸和动画均保持下载状态。

## 文件验证

已核对 32/32 个节点及不同模型的对应关系、GLB 2.0 文件头与长度、内嵌资源和 SHA-256；全部模型均无外部纹理或缓冲依赖。另在 Godot 4.7.2 中逐个加载并实例化，确认 32/32 个模型都有有效网格及有限包围盒，并完成实际显卡渲染预览。模型尺寸、原始朝向各不相同，使用时需统一显示尺度。
