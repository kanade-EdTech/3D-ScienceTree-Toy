# 快速开始指南 (Quick Start Guide)

> 适用版本：**v1.3.0** | 引擎要求：**Godot 4.7+**（推荐 4.7.2）

---

## 一、 运行方式

### 方式 1：使用 Godot 编辑器直接运行（推荐开发者）
1. 下载并安装 [Godot 4.7+](https://godotengine.org/download/)。
2. 打开 Godot 项目管理器，点击 **导入 (Import)**，选择本项目根目录下的 `project.godot`。
3. 按 `F5` 运行主场景（`res://scenes/main.tscn`）。

### 方式 2：直接运行 Web 导出预览（免打开编辑器）
如果已导出 `dist/3D-TechnologyTree-1.3.0-Toy-Web.zip` 或 `build/toy-web/`，可在项目根目录运行内置预览服务器：
```powershell
python tools/serve_toy_web.py
```
随后在浏览器访问 `<http://127.0.0.1:8876/preview.html>` 即可体验（包含桌面鼠标与移动端触屏按钮）。

## 二、 30 秒操作速查卡

本项目采用 **“固定中轴线 + 旋转/平移分离”** 的直观物理操控模型：
- **垂直于中轴线拖动** = **绕轴翻滚旋转** 🔄
- **平行于中轴线拖动** = **抓住画面沿轴平移** ↕️↔️

### 1. 从上到下模式（默认：垂直 Y 轴为中轴）
| 操作 | 效果 | 说明 |
| :--- | :--- | :--- |
| **左右拖动** `←` `→` | **绕垂直轴翻滚旋转** | 360° 环视各层科技圆盘 |
| **上下拖动** `↑` `↓` | **沿垂直轴平移画面** | 上拖看更深层（Tier 4），下拖看起源层（Tier 0） |
| **鼠标滚轮** | **缩放视距** | 在 10 ~ 70 单位之间拉近看细节或推远看全景 |
| **左键单击节点** | **解锁科技** | 需满足前置科技条件且科技点充足 |

### 2. 从左到右模式（水平 X 轴为中轴）
| 操作 | 效果 | 说明 |
| :--- | :--- | :--- |
| **上下拖动** `↑` `↓` | **绕水平轴翻滚旋转** | 调整俯仰观察角度 |
| **左右拖动** `←` `→` | **沿水平轴平移画面** | 左拖看现代前沿（Tier 4），右拖看文艺复兴起源（Tier 0） |
| **鼠标滚轮** | **缩放视距** | 拉近或推远 |
| **左键单击节点** | **解锁科技** | 消耗科技点解锁节点 |

### 3. 快捷键与触屏按钮
| 按键 / 按钮 | 功能 |
| :--- | :--- |
| `PageDown` / 界面**方向按钮** | 在 **“从上到下”** 与 **“从左到右”** 两种三维布局间平滑切换（0.8 秒过渡动画） |
| `PageUp` / 界面**速度按钮** | 切换科技点自动增长倍率（`1x` → `2x` → `4x` → `8x`） |
| 界面 **`+` / `-` 按钮** | 放大 / 缩小视距（方便触屏与无滚轮设备） |

| 🟣 **紫色 (`#8B5CF6`)** | 地球与环境科学 | 近代地质学与古生物学 → 地球系统科学与气候动力学 |

### 2. 节点与连线状态
* **节点状态**：
  * **明亮发光 + 白色标签**：已解锁
  * **领域色半亮 + 黄色标签**：前置已满足，可点击解锁
  * **深灰暗淡 + 灰色标签**：锁定状态（前置未满足）
* **连线状态**：
  * **绿色连线**：前序与后继节点均已解锁
  * **黄色连线**：前序节点已解锁，正在赋能目标节点
  * **灰色连线**：前序节点尚未解锁

## 四、 常见问题 (FAQ)

* **Q: 为什么点击某个科技球没有解锁？**
  * **A**: 请将鼠标悬停在该节点上查看提示框：若状态为“锁定”，需顺着灰色连线先解锁上一层的前置科技；若状态为“可解锁”，请确认左上角“科技点”是否达到该节点的消耗点数（3~9 点）。
* **Q: 拖动视角时松开鼠标会误买科技吗？**
  * **A**: 不会。系统具有严格的点击与拖动阈值仲裁（6 像素阈值），只有原地按下并在同一节点松开才会触发解锁；拖动、按 `Esc` 或切换布局均会自动取消点击。
* **Q: 如何重置视角？**
  * **A**: 连按两次 `PageDown`（切换布局再切回）即可将翻滚角与平移焦点重置为默认全景状态。
