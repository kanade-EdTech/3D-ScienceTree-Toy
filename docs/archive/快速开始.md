# 3D科技树 - 快速开始指南

## 运行游戏

### 方法一：使用Godot编辑器
1. 下载并安装 [Godot 4.x](https://godotengine.org/download/)
2. 打开Godot，点击"导入"
3. 选择本项目文件夹中的 `project.godot` 文件
4. 点击"导入并编辑"
5. 在编辑器中按 `F5` 键运行游戏

### 方法二：导出可执行文件
1. 在Godot编辑器中，点击 "项目" -> "导出"
2. 添加您的目标平台（Windows, macOS, Linux）
3. 点击"导出项目"并选择保存位置
4. 运行生成的可执行文件

## 基本操作

### 鼠标控制
- **左键点击科技球**: 解锁科技（需要足够点数）
- **鼠标悬停**: 查看科技详情
- **右键拖动**: 旋转视角
- **滚轮**: 缩放

### 键盘控制
- **W/A/S/D**: 移动相机
- **PageUp**: 切换时间速度 (1x → 2x → 4x → 8x)

## 游戏流程

1. **开始游戏**
   - 初始科技点: 0
   - 可用科技: 4个（第0层）
   - 时间速度: 1x

2. **积累科技点**
   - 科技点每秒自动增加
   - 可以加速时间来快速积累
   - 每个科技需要 3-9 点解锁

3. **解锁科技**
   - 从第0层开始解锁基础科技
   - 解锁后会开放依赖它的下一层科技
   - 按照科学发展的历史顺序推进

4. **完成游戏**
   - 解锁全部 32 个科技节点
   - 体验从文艺复兴到现代AI的科学发展历程

### 节点状态
- **明亮发光**: 已解锁
- **黄色高亮**: 可以解锁
- **暗灰色**: 尚未满足条件

### 连接线颜色
- **绿色**: 两端都已解锁
- **黄色**: 起点已解锁，终点可解锁
- **灰色**: 尚未激活

## 技术要求

## 常见问题

**Q: 为什么有些科技点不了？**
A: 需要先解锁它的前置科技。悬停鼠标查看需要多少个前置科技。

**Q: 如何加速游戏？**
A: 按 PageUp 键可以在 1x/2x/4x/8x 之间切换时间速度。

**Q: 科技球太小看不清？**
A: 使用鼠标滚轮放大，或者移动相机(WASD)靠近查看。

**Q: 可以跳过某些科技吗？**
A: 不可以。这是基于真实科学发展历史的依赖关系，必须按顺序解锁。
