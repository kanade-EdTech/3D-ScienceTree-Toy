# 3D科技树游戏 - 使用说明

## 游戏概述
这是一个使用Godot 4.x引擎开发的3D科技树游戏，展示了人类近代科学发展的32个关键节点，从文艺复兴时期一直到现代科学。

## 游戏机制

### 科技点系统
- **自动生成**: 科技点每秒自动增加1点
- **速度控制**: 按`PageUp`键可以在1x、2x、4x、8x之间切换速度
- **解锁成本**: 每个科技需要3-9个科技点来解锁（随机分配）

### 科技解锁规则
1. **起始科技**: 游戏开始时，第0层（文艺复兴时期）的4个科技可以直接解锁
2. **前置条件**: 解锁更高层级的科技需要先解锁它的前置科技
3. **渐进式解锁**: 必须从开头逐步解锁到最高层（第4层）

### 科技树结构
- **第0层**: 天文观测、大地测量、炼金术、人体解剖（4个科技）
- **第1层**: 解析几何、几何光学、经典力学等（6个科技）
- **第2层**: 分析力学、热力学、电磁学等（7个科技）
- **第3层**: 相对论、量子力学等（9个科技）
- **第4层**: 天体物理、人工智能、基因组学等（6个科技）

## 操作控制

### 相机控制
- **WASD键**: 移动相机位置
- **鼠标右键 + 拖动**: 旋转视角
- **鼠标滚轮**: 缩放视距

### 交互操作
- **鼠标左键点击**: 解锁科技节点（需要足够的科技点且满足前置条件）
- **鼠标悬停**: 显示科技详细信息（名称、成本、状态、前置科技数量）
- **PageUp键**: 切换时间速度倍率

## 视觉反馈

### 节点颜色
- **亮色发光**: 已解锁的科技
- **黄色提示**: 可以解锁的科技（满足前置条件）
- **灰色暗淡**: 锁定状态（需要先解锁前置科技）

### 学科分类颜色
- **蓝色**: 天文与物理
- **橙色**: 测量、数学与信息
- **绿色**: 炼金、化学与材料
- **红色**: 解剖、生物与医学
- **紫色**: 地球与环境科学

## UI界面

### 主要信息
- **科技点**: 当前拥有的科技点数量
- **速度**: 当前时间流速倍率
- **已解锁**: 已解锁/总计科技数量

### 悬浮提示框
鼠标悬停在科技节点上时显示：
- 科技名称（中文）
- 解锁成本
- 当前状态（已解锁/可解锁/锁定）
- 需要的前置科技数量

## 游戏目标
从文艺复兴时代的基础科学出发，逐步解锁所有32个科技节点，最终达到现代科学的巅峰，包括人工智能、量子信息科学和合成生物学等前沿领域。

## 技术特点
- 完全使用UI文字展示，无需复杂的3D模型
- 真实的科学发展历史作为游戏内容
- 有向无环图（DAG）结构确保合理的科技依赖关系
- 流畅的3D相机控制和视觉反馈
