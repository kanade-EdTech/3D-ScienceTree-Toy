# 3D科技树 - 立体圆盘布局系统

## 🎯 核心设计理念

### 真正的3D立体化
每一层（Tier）不再是一条线，而是一个**立体圆盘**结构：
- 每个圆盘是一个完整的3D几何体
- 节点环绕分布在圆盘周围
- 具有随机高度变化，形成起伏的立体感
- 圆盘半径随层级递增，展现科技树的扩展性

---

## 🌀 圆盘布局结构

### 圆盘形成原理

```
        节点3
         ⚫
    
  节点2 ⚫    ⚫ 节点4
  
        ⚫
       节点1
       
每个圆盘：
• 节点均匀分布在圆周上
• 半径 = 8 + 层级 × 2（越高层越大）
• 高度有±1.5的随机变化
• 最少按4个点分布（即使只有1个节点）
```

### 层级堆叠

#### 横向模式（默认）
```
    Tier 0圆盘 → Tier 1圆盘 → Tier 2圆盘 → Tier 3圆盘 → Tier 4圆盘
    (X=0)       (X=12)      (X=24)      (X=36)      (X=48)
    
    时间轴 ──────────────────────────────────────────────>
```

#### 纵向模式
```
    Tier 0圆盘 (Y=0)
         ↓
    Tier 1圆盘 (Y=-15)
         ↓
    Tier 2圆盘 (Y=-30)
         ↓
    Tier 3圆盘 (Y=-45)
         ↓
    Tier 4圆盘 (Y=-60)
```

## 🎮 全新交互方式

### A/D 键 - 绕圆盘轨道旋转
- **A键**：逆时针绕当前圆盘旋转
- **D键**：顺时针绕当前圆盘旋转
- 相机保持距离，环绕观察圆盘
- 可以从不同角度查看节点分布

### Q/E 键 - 层级跳转
- **Q键**：跳转到前一个圆盘（Tier减少）
- **E键**：跳转到下一个圆盘（Tier增加）
- 相机焦点在圆盘之间切换
- 适合逐层深入浏览

### W/S 键 - 缩放
- **W键**：拉近（减小距离）
- **S键**：推远（增大距离）
- 范围：8-60单位
- 可以近距离观察节点细节

### 鼠标右键 - 自由旋转
- 拖动改变俯仰角和偏航角
- 不受轨道旋转限制
- 可以从任意角度观察

### PageDown - 切换布局
- 横向 ⇄ 纵向切换
- 圆盘结构保持，只是堆叠方向改变
- 0.8秒平滑过渡动画

## 📐 技术实现细节

### 圆盘位置计算

```gdscript
func calculate_disc_position(tier, index, total_in_tier, layout):
    # 1. 计算角度
    var angle_step = TAU / max(total_in_tier, 4)
    var angle = angle_step * index
    
    # 2. 计算半径（随层级增长）
    var radius = 8.0 + tier * 2.0
    
    # 3. 圆周坐标
    var x_offset = cos(angle) * radius
    var z_offset = sin(angle) * radius
    
    # 4. 立体高度变化
    var y_variation = randf_range(-1.5, 1.5)
    
    # 5. 根据布局模式组合
    if 横向:
        return (tier*12, z_offset+y_var, x_offset)
    else:
        return (x_offset, -tier*15+y_var, z_offset)
```

### 相机焦点系统

```gdscript
# 相机始终聚焦在某个圆盘的中心
focus_center = get_focus_center()

# 横向模式：聚焦点沿X轴
focus_center = (focus_tier * 12, 0, 0)

# 纵向模式：聚焦点沿Y轴
focus_center = (0, -focus_tier * 15, 0)

# 相机围绕焦点旋转
camera_pos = focus_center + offset
look_at(focus_center)
```

## 🎨 视觉特点

### 1. 层次感强烈
- 圆盘半径递增：Tier 0最小，Tier 4最大
- 展现科技树的"扩展性"和"复杂度递增"

### 2. 真3D立体
- 不是平面圆，而是有高度起伏的立体圆盘
- ±1.5的随机高度变化
- 避免单调的平面感

### 3. 连接线立体交织
- 跨层连接形成3D空间中的网络
- 从不同角度观察有不同的视觉体验
- 绿/黄/灰三色状态清晰可见

### 4. 动态视角
- 轨道旋转：环绕欣赏单个圆盘
- 层级跳转：快速在圆盘间切换
- 自由旋转：任意角度观察

## 💡 使用场景

### 场景1：全局浏览
```
1. 使用Q/E快速浏览各层圆盘
2. 每个圆盘停留2-3秒
3. 了解整体结构
```

### 场景2：专注某层
```
1. Q/E跳转到目标层级
2. A/D绕圆盘旋转一周
3. 观察该层所有科技节点
4. 点击解锁
```

### 场景3：追踪连接
```
1. 解锁某个节点
2. 观察连接线从灰变黄/绿
3. Q/E跳到下一层
4. 找到被激活的后续节点
```

### 场景4：对比布局
```
1. 横向模式：强调时间进程
2. PageDown切换
3. 纵向模式：俯瞰层级结构
4. 比较两种视角的差异
```

### 间距参数

- **层间距（纵向）**: 15单位
- **高度变化**: ±1.5单位
- **节点球体半径**: 0.5单位

### 相机参数
- **初始距离**: 25单位
- **距离范围**: 8-60单位
- **俯仰角**: -35°（横向）/ -55°（纵向）
- **轨道速度**: 0.5弧度/秒
