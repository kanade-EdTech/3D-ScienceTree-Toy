# 3D科技树 - 拖动翻滚操作系统

## 🎯 设计理念

**极简操作，极致体验**
- 只用鼠标左键和滚轮完成所有操作
- 直观的拖动翻滚，如同翻阅3D书籍
- 固定中轴线保持方向感

---

## 🔀 两种发展方向

### 📊 从上到下（默认）

```
    Tier 0 圆盘
         ↓
    Tier 1 圆盘
         ↓
    Tier 2 圆盘
         ↓
    Tier 3 圆盘
         ↓
    Tier 4 圆盘
```

**特点：**
- 科技树从上往下发展（Y轴负方向）
- 符合"科技树"的经典视觉习惯
- 俯视角度观察整体结构

**翻滚方式：**
- **左右拖动** → 绕垂直中轴线左右旋转
- **上下拖动** → 前后倾斜（改变俯视角度）

---

### 📊 从左到右

```
Tier 0 → Tier 1 → Tier 2 → Tier 3 → Tier 4
圆盘      圆盘      圆盘      圆盘      圆盘
```

**特点：**
- 科技树从左往右推进（X轴正方向）
- 强调时间线的横向发展
- 侧视角度观察历史进程

**翻滚方式：**
- **上下拖动** → 绕水平中轴线上下旋转
- **左右拖动** → 前后倾斜（改变侧视深度）

---

## 🖱️ 操作方法

### 左键拖动 - 翻滚视角

**操作：**
1. 在空白处按住鼠标左键
2. 拖动鼠标改变视角
3. 释放鼠标停止翻滚

**效果：**

#### 从上到下模式
```
左右拖 ← →  =  相机绕垂直轴旋转
                （环视圆盘周围）

上下拖 ↑ ↓  =  俯视角度调整
                （从正上方到斜上方）
```

#### 从左到右模式
```
上下拖 ↑ ↓  =  相机绕水平轴旋转
                （从侧面到斜上/斜下）

左右拖 ← →  =  深度角度调整
                （观察角度的前后偏移）
```

### 滚轮 - 缩放距离

**操作：**
- **向上滚** → 拉近（距离减小）
- **向下滚** → 推远（距离增大）

**范围：**
- 最近：10单位（仔细观察单个节点）
- 最远：70单位（俯瞰整体结构）
- 推荐：30单位（平衡视野）

### 点击节点 - 解锁科技

**操作：**
- 鼠标悬停：查看科技详情
- 鼠标左键单击：解锁科技（消耗点数）

**注意：**
- 拖动时不会触发点击
- 只有松开后的单击才会解锁

### PageDown - 切换方向

**操作：**
- 按 `PageDown` 键切换发展方向
- 从上到下 ⇄ 从左到右

**效果：**
- 所有节点平滑移动到新位置（0.8秒）
- 翻滚角度自动重置
- 中轴线重新计算

## 🎯 固定中轴线系统

### 什么是中轴线？

中轴线是科技树旋转的"脊柱"，保持方向感和稳定性。

### 从上到下模式

```
        中轴线（垂直）
           ↓
           │
    ⚫ ─── │ ─── ⚫
           │
        ⚫ │ ⚫
           │
    ⚫ ─── │ ─── ⚫
           │
```

- 中轴线：Y轴（垂直向下）
- 位置：(0, -30, 0) - 所有圆盘的中心
- 旋转：左右拖动时，相机绕此轴旋转

### 从左到右模式

```
中轴线（水平）→ → → → →
               
⚫    ⚫    ⚫    ⚫    ⚫
│    │    │    │    │
⚫    ⚫    ⚫    ⚫    ⚫
```

- 中轴线：X轴（水平向右）
- 位置：(24, 0, 0) - 所有圆盘的中心
- 旋转：上下拖动时，相机绕此轴旋转

### 为什么需要中轴线？

1. **方向感**：始终知道科技树的主发展方向
2. **稳定性**：翻滚时不会"迷失"
3. **直观性**：旋转行为符合物理直觉
4. **连贯性**：多次翻滚保持一致性

## 💡 使用技巧

### 技巧1：全局浏览

```
1. 推远视距（滚轮向下）
2. 缓慢左右拖动一圈
3. 观察所有圆盘的整体布局
4. 切换到另一个方向重复
```

### 技巧2：专注某层

```
1. 拉近视距（滚轮向上）
2. 拖动调整到最佳角度
3. 观察该层圆盘的细节
4. 点击解锁感兴趣的科技
```

### 技巧3：追踪连接

```
1. 解锁某个节点
2. 观察连接线颜色变化
3. 拖动翻滚找到下游节点
4. 继续解锁形成路径
```

### 技巧4：对比方向

```
1. 在"从上到下"模式熟悉结构
2. 按PageDown切换到"从左到右"
3. 观察同一科技树的不同呈现
4. 理解时间线vs层级结构
```

## 🔧 技术参数

### 翻滚灵敏度
- **drag_sensitivity**: 0.3
- **换算**：1像素拖动 = 0.003弧度旋转
- **完整旋转**：约需要拖动2000像素

### 缩放参数
- **zoom_speed**: 2.0单位/滚轮格
- **min_distance**: 10单位
- **max_distance**: 70单位
- **初始距离**: 30单位

### 中轴线位置
- **纵向模式**: (0, -30, 0)
- **横向模式**: (24, 0, 0)

### 初始视角
- **纵向模式**: 俯角60°，正上方
- **横向模式**: 俯角45°，侧面

## ⚠️ 注意事项

### 拖动vs点击

系统会区分拖动和点击：
- **拖动**：鼠标移动距离 > 阈值 → 翻滚视角
- **点击**：按下和松开位置相同 → 解锁节点

### 翻滚限制

为避免视角混乱，翻滚有合理限制：
- **俯仰角**：约-90° ~ +30°（不会倒转）
- **旋转角**：360°无限制（可以转圈）

### 性能优化

- 拖动时实时更新相机位置
- 无卡顿，60fps流畅运行
- 圆盘和连接线自动裁剪
