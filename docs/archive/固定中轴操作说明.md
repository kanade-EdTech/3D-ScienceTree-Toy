# 3D科技树 - 固定中轴线操作系统

## 🎯 核心设计理念

**固定中轴线 + 分离式拖动**
- 中轴线是科技树的"脊柱"，永不改变
- 垂直于轴的拖动 = 翻滚旋转
- 平行于轴的拖动 = 沿轴平移
- 1.3.0 平移采用抓住画面拖动：内容跟随鼠标，纵向上拖内容上移，横向右拖内容右移
- 清晰的物理模型，直观易懂

| **上下拖动** ↑ ↓ | **沿轴平移** | 内容跟随鼠标上下移动，查看不同层级 |

## 🖱️ 详细操作说明

### 左键拖动 - 翻滚或平移

#### 从上到下模式

```
拖动方向          效果                视觉变化
───────────────────────────────────────────────
← 左拖     →   绕Y轴逆时针旋转    相机向左移动，看到圆盘右侧
→ 右拖     →   绕Y轴顺时针旋转    相机向右移动，看到圆盘左侧
↑ 上拖     →   内容向上移动        浏览更下层的圆盘（Tier 4）
↓ 下拖     →   内容向下移动        浏览更上层的圆盘（Tier 0）
```

**示意图：**
```
       左拖 ←              → 右拖
           ╲            ╱
            ╲          ╱
             ⚪相机⚪  ← 绕Y轴旋转
            ╱          ╲
           ╱            ╲
                │
                │ ← 固定Y轴
      ↑ 上拖    │    ↓ 下拖
      （平移）   │   （平移）
```

#### 从左到右模式

```
拖动方向          效果                视觉变化
───────────────────────────────────────────────
↑ 上拖     →   绕X轴旋转向上       相机抬高，俯视角度增大
↓ 下拖     →   绕X轴旋转向下       相机降低，仰视角度增大
← 左拖     →   内容向左移动        浏览更晚期的圆盘（Tier 4）
→ 右拖     →   内容向右移动        浏览更早期的圆盘（Tier 0）
```

**示意图：**
```
        ↑ 上拖（旋转）
         ╲
          ╲
           ⚪相机
          ╱
         ╱
        ↓ 下拖（旋转）

  ← 左拖     ───────────→     → 右拖
  （平移）   固定X轴中轴线      （平移）
```

### 滚轮 - 缩放距离

**操作：**
- **向上滚** → 拉近（距离减小）
- **向下滚** → 推远（距离增大）

**范围：**
- 最近：10单位
- 最远：70单位
- 推荐：30单位

**效果：**
- 拉近：细看单个节点和连接线
- 推远：俯瞰整体结构和全局布局

### 左键点击节点 - 解锁科技

**操作：**
- 鼠标悬停：查看科技名称和详情
- 左键单击：消耗点数解锁科技

**注意：**
- 系统自动区分拖动和点击
- 只有原地单击才会触发解锁
- 拖动后松开不会触发点击

### PageDown - 切换发展方向

**操作：**
- 按 `PageDown` 键

**效果：**
- 从上到下 ⇄ 从左到右
- 所有节点平滑移动（0.8秒）
- 翻滚角度和平移偏移重置
- 中轴线重新计算

## 🎯 固定中轴线的优势

### 1. 清晰的空间参考

**从上到下：**
```
    你始终知道：
    • 中轴是垂直的
    • 上方是起源（Tier 0）
    • 下方是前沿（Tier 4）
    • 左右是观察角度的变化
```

**从左到右：**
```
    你始终知道：
    • 中轴是水平的
    • 左侧是过去（Tier 0）
    • 右侧是未来（Tier 4）
    • 上下是观察高度的变化
```

### 2. 分离式操作逻辑

| 操作类型 | 从上到下 | 从左到右 |
|---------|---------|---------|
| 翻滚旋转 | 左右拖动 | 上下拖动 |
| 沿轴平移 | 上下拖动 | 左右拖动 |

**规律：**
- 垂直于轴 = 翻滚
- 平行于轴 = 平移

### 3. 物理直觉

就像现实中的操作：
- 翻滚一个竖直的筒 → 左右转动它
- 移动焦点看筒的不同部分 → 上下移动视线
- 翻滚一个水平的轴 → 上下转动它
- 移动焦点看轴的不同部分 → 左右移动视线

## 🎨 视觉反馈

### 翻滚旋转时

- **节点位置不变**：圆盘保持原位
- **相机环绕移动**：你围绕中轴线移动
- **连接线动态变化**：3D深度感明显
- **中轴线始终可见**：方向感不丢失

### 沿轴平移时

- **焦点沿轴移动**：中轴线固定，画面内容跟随鼠标平移
- **相机跟随平移**：保持与焦点的相对位置
- **不同层级进入视野**：平滑过渡
- **翻滚角度保持**：观察角度不变

### 缩放时

- **焦点不变**：始终看向当前焦点
- **距离改变**：相机远离或靠近
- **视野范围变化**：近看细节，远看全局
- **深度感变化**：近处强，远处弱

## 🔧 技术参数

### 翻滚旋转
- **灵敏度**：0.005弧度/像素
- **范围**：360°无限制
- **平滑度**：实时更新，无延迟

### 沿轴平移
- **速度**：0.05单位/像素
- **范围**：可覆盖所有层级
- **对应关系**：
  - 从上到下：Y轴范围 0 ~ -60
  - 从左到右：X轴范围 0 ~ 48

### 缩放
- **速度**：2单位/滚轮格
- **最小距离**：10单位
- **最大距离**：70单位
- **初始距离**：按科技树范围自动计算，在 10–70 单位内适配全景
- **默认观察角**：纵向俯角 30°，横向侧视角 -30°

### 中轴线位置
- **从上到下**：(0, -30, 0) - Y轴中点
- **从左到右**：(24, 0, 0) - X轴中点

## ⚠️ 常见问题

### Q: 为什么左右拖动有时旋转，有时平移？

A: 取决于当前发展方向：
- **从上到下**：左右拖动是旋转（垂直于Y轴）
- **从左到右**：左右拖动是平移（平行于X轴）

### Q: 中轴线在哪里？

A: 中轴线是虚拟的参考线：
- **从上到下**：穿过所有圆盘中心的垂直线
- **从左到右**：穿过所有圆盘中心的水平线

虽然不可见，但相机行为完全围绕它。

### Q: 如何回到初始视角？

A: 按 `PageDown` 两次：
1. 切换到另一方向
2. 再切换回来
3. 翻滚和平移会自动重置

### Q: 拖动和点击会冲突吗？

A: 不会，系统自动区分：
- **拖动**：鼠标移动距离较大
- **点击**：按下和松开位置接近

## 🌟 设计哲学

### 为什么采用固定中轴线？

1. **物理真实性**
   - 现实世界的旋转物体都有轴心
   - 符合人的空间认知习惯
   - 降低学习成本

2. **操作可预测性**
   - 同样的拖动产生同样的效果
   - 不会"迷失"在3D空间
   - 易于掌握和记忆

3. **功能分离性**
   - 旋转和平移互不干扰
   - 清晰的操作映射
   - 减少误操作

4. **视角稳定性**
   - 始终有方向参考
   - 翻滚时不会"翻车"
   - 适合长时间使用
