# 玩法与固定中轴操作手册 (Gameplay & Fixed-Axis Controls Guide)

## 一、 游戏概述与核心机制

**3D-ScienceTree-Toy** 是一款基于真实近代科学史的有向无环图（DAG）3D 微型严肃游戏。玩家将从 15–16 世纪文艺复兴时期的四大经验源头（**天文观测、大地测量、炼金冶金、人体解剖**）出发，跨越 5 个历史世代（Tier 0 ~ Tier 4），亲手点亮 32 个核心学科节点与 69 条跨学科赋能连线。

### 1. 科技点与时间倍率
* **自动积累**：科技点默认以基础速率（`1 点/秒`）随时间自动增长。
* **四档加速**：按 `PageUp` 或点击界面速度按钮，可在 `1x`、`2x`、`4x`、`8x` 之间循环切换。
* **解锁成本**：每个科技节点的研发消耗为 `3 ~ 9` 点。

### 2. 跨学科前置解锁规则 (DAG)
* **起始层（Tier 0）**：开局即可直接解锁四大先导源头节点。
* **多重前置依赖**：近代细分学科往往由多个前序学科交叉诞生（例如“经典力学”同时需要“天文观测”、“大地测量”与“微积分”三个前置节点全部解锁后才变为可解锁状态）。
* **悬停详情**：鼠标悬停或触屏点按节点可查看科技名称、消耗点数、解锁状态及所需前置科技数量。

## 二、 立体圆盘与固定中轴线系统

### 1. 立体圆盘结构 (3D Disc Layout)
每一历史世代（Tier 0 ~ Tier 4）在三维空间中排布为一个**立体圆盘**：
* 圆盘半径随时代演进逐层递增（$\text{Radius} = 8 + \text{Tier} \times 2$），直观呈现人类知识疆域的扩张。
* 节点在圆盘上具有经过避让优化的固定立体起伏高度（定义于 [`tech_layout.json`](../tech_layout.json)），确保全部 32 个节点与 69 条连线在空间与默认视角下互不遮挡穿模。

### 2. 固定中轴线 + 分离式操控
为了彻底解决传统 3D 自由相机容易“迷失方向、万向节死锁、旋转与平移混杂”的痛点，本项目采用**固定中轴线（Fixed Central Axis）**设计：

#### 模式 A：从上到下（默认，垂直 Y 轴为中轴）
```text
         │ ← 固定垂直中轴线 (Y轴, X=0, Z=0)
    ⚫⚫⚫⚫│⚫⚫⚫⚫  Tier 0 (文艺复兴, Y=0)
         ↓
    ⚫⚫⚫⚫│⚫⚫⚫⚫  Tier 1 (科学革命, Y=-15)
         ↓
    ⚫⚫⚫⚫│⚫⚫⚫⚫  Tier 2 ~ Tier 4 (直至 Y=-60)
```
* **左右拖动 (`←` / `→`)**：相机绕垂直 Y 轴 360° 翻滚旋转，环视每一层圆盘的学科分布。
* **上下拖动 (`↑` / `↓`)**：抓住画面沿垂直 Y 轴上下平移焦点，浏览不同世代层级。
* **默认观察角**：俯视角 `30°`，开局自动适配全景视距。

#### 模式 B：从左到右（水平 X 轴为中轴）
```text
    ⚫⚫    ⚫⚫⚫    ⚫⚫⚫    ⚫⚫⚫⚫    ⚫⚫⚫
    │      │       │       │       │
  ──┴──────┴───────┴───────┴───────┴──→ 固定水平中轴线 (X轴, Y=0, Z=0)
  Tier 0  Tier 1  Tier 2  Tier 3  Tier 4 (X=0 ~ 48)
```
* **上下拖动 (`↑` / `↓`)**：相机绕水平 X 轴 360° 翻滚旋转，调整仰俯观察角度。
* **左右拖动 (`←` / `→`)**：抓住画面沿水平 X 轴左右平移焦点，顺着历史时间线从过去浏览至未来。
* **默认观察角**：侧视角 `-30°`。

## 三、 核心控制参数一览

| 参数项 | 从上到下（纵向模式） | 从左到右（横向模式） |
| :--- | :--- | :--- |
| **固定中轴线** | 垂直 Y 轴 (`Y: 0 ~ -60`，中点 `(0, -30, 0)`) | 水平 X 轴 (`X: 0 ~ 48`，中点 `(24, 0, 0)`) |
| **层间距离** | `15.0` 世界单位 | `12.0` 世界单位 |
| **翻滚旋转灵敏度** | `0.005 rad/px`（左右拖动，360° 连续无死锁） | `0.005 rad/px`（上下拖动，360° 连续无死锁） |
| **沿轴平移速度** | `0.05 unit/px`（上下抓住画面拖动） | `0.05 unit/px`（左右抓住画面拖动） |
| **滚轮缩放范围** | `10.0 ~ 70.0` 单位（步长 `2.0` 单位/格） | `10.0 ~ 70.0` 单位（步长 `2.0` 单位/格） |
| **默认观察角度** | 俯角 `30°` | 侧视角 `-30°` |
| **点击/拖动判定阈值** | `6.0 px`（越过阈值补齐累计位移且不触发购买） | `6.0 px`（越过阈值补齐累计位移且不触发购买） |
