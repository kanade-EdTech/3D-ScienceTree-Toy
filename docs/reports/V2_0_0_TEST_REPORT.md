# 2.0.0 测试与修正报告

日期：2026-10-25。环境：Windows、Godot 4.7.2、OpenGL Compatibility、1280×720；实际渲染 GPU 为 NVIDIA GeForce RTX 4060 Laptop GPU。

**结论：九组共 2788 项检查全部通过，最终日志无脚本错误或警告。** 另在实际图形窗口完整执行 666 项全模型检查，通过。全部 32 个节点均加载对应模型。

## 本轮内容与修正

- **全节点模型覆盖**：保留新增的 Tier 4 六个模型，当前 Tier 0–4 共 32 个模型全部参与测试。前置依赖按数据图排序，未依赖 JSON 记录顺序。
- **新版状态配色**：保留深绿色可用状态 (0.2,0.8,0.3)，能量 2.2；深卡其色解锁状态 (0.76,0.60,0.30)，能量 2.0。锁定状态关闭灯光和光晕。
- **版本标识滞后**：工程仍标记 1.6.0，已将工程、中英文科技树数据、当前版本断言、README 和资源使用说明同步为 2.0.0。导出脚本自动读取新版本。
- **地球仪测试代理误判**：旧的三角网格测试体挂在模型网格下，继承约 356 倍的网格缩放，导致采样未命中。改为把网格三角形变换到世界坐标，用单位变换的临时测试体进行射线采样，消除极端缩放对测试代理的影响。双面碰撞使用 ConcavePolygonShape3D.backface_collision，属性依据见 [Godot 官方说明](https://docs.godotengine.org/en/stable/classes/class_concavepolygonshape3d.html)。
- **扣点诊断记录**：分别记录拖动后的扣点和正常点击后的扣点，避免把后续正常购买金额混入拖动结果。

地球仪最终所测近景有 201 个网格命中采样，节点拾取遗漏为 0；实际模型可见、可点击且解锁正常。修正发生在测试代理中，未放宽游戏拾取范围。32 个原始 GLB 的 SHA-256 均与下载清单一致。

本轮未复现新的购买、前置解锁或布局切换游戏逻辑缺陷；修正主要为版本配置与测试可靠性问题。

## 复测方式

全部九组命令见项目 README。模型专项沿用已有文件名：

~~~powershell
& "$env:LOCALAPPDATA\Programs\Godot\4.7.2\Godot_v4.7.2-stable_win64_console.exe" --headless --path . --script res://tests/test_tier0_models.gd
~~~

添加 -- --render 可执行图形检查，TECH_TREE_MODEL_TEST_OUTPUT 环境变量设置截图位置。测试不等同于操作系统级鼠标自动化。
