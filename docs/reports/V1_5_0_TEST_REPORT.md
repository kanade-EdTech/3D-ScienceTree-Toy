# 1.5.0 修复与复测报告

日期：2026-10-25。应用与中英文数据版本：1.5.0。环境：Windows、Godot 4.7.2、OpenGL Compatibility、1280×720。

结论：**九组共 2300 项检查全部通过，最终日志无脚本错误或警告。** 另通过实际显卡渲染下的 178 项模型专项检查。Web 导出及 ZIP 完整性检查通过。

## 修复内容

1. **模型状态更新报错及标签不刷新**：移除不存在的 Node3D.modulate。为每个模型实例复制材质，用原始颜色调节状态亮度，统一刷新黄色可用标签、白色已解锁标签及灰色锁定标签。状态灯光在首次刷新前创建，保留可用绿色、已解锁卡其色、锁定关闭的设计。
2. **鼠标按下误购买与重复信号**：移除节点 Area3D 中的购买入口。相机在同一节点松开、未超过拖动阈值、手势未取消时统一确认购买。按下不扣点，拖动、Esc、失焦及切换方向取消待购买；一次点击只发一次信号。
3. **模型尺寸、偏移与拾取范围不一致**：按完整模型包围盒统一居中，最大尺寸归一到 1 个单位；用独立几何层保存归一化，外层容器负责解锁脉冲。拾取盒按归一后的尺寸生成，并覆盖 1.3 倍脉冲和小幅余量。尤其修正量角器约 760158 单位、心脏约 59 单位、苹果约 0.2 单位等原始尺寸差异。
4. **缺失资源回退状态不完整**：始终准备球体材质，模型不存在或不可用时继续刷新球体与标签状态，不留下空的模型容器。
5. **版本配置和 Web 包版本滞后**：工程配置、数据及当前测试更新为 1.5.0；打包脚本从工程读取版本，移除写死的 1.3.0。Web 包随附项目、模型和字体的版权与许可文本。

GLB 源文件保留下载内容；居中、缩放、状态材质均在运行时对实例处理。

## 实际渲染复测

使用 NVIDIA GeForce RTX 4060 Laptop GPU 运行相同专项检查，178 项通过，保存初始全景、十个模型近景和两个布局的截图。量角器、心脏等模型能够正常显示，不再以原始尺寸进入场景。

复测中修正了测试脚本的输入模拟方式：有窗口时通过 Input.parse_input_event 同步全局鼠标按键状态；无界面时使用视口事件。此前直接向图形视口投递事件不更新全局按键状态，可能与真实窗口鼠标事件冲突。最终两种模式分别完整通过，游戏的手势取消规则不作放宽。

## 复测命令

全部九组命令见项目 README。十模型专项沿用现有测试文件名：

~~~powershell
& "$env:LOCALAPPDATA\Programs\Godot\4.7.2\Godot_v4.7.2-stable_win64_console.exe" --headless --path . --script res://tests/test_tier0_models.gd
~~~

添加 -- --render 可执行图形模式并保存截图；输出目录可用 TECH_TREE_MODEL_TEST_OUTPUT 环境变量设置。输入测试为 Godot 事件和物理拾取，不等同于操作系统级鼠标自动化。本轮未执行跨平台或长时间稳定性测试。
