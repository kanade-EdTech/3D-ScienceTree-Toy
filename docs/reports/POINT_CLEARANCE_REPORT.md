# 1.3.0 点位避让修复报告

日期：2026-10-24。Godot 4.7.2，Windows，1280×720，默认 30° 观察角。

已扫描全部 32 个节点与 69 条连线。排除每条连线自身的两个端点，每种布局有 2,070 对节点/无关连线组合。

## 修复结果

- 修正“分析力学与流体力学”贴在“解析几何与微积分 → 概率统计、群论与非欧几何”长连线上的问题，并微调其他同类位置。
- 点位修正保存在 `tech_layout.json`，按两种布局分别配置。固定原有范围内的立体高度，避免每次启动随机改变重合情况。每个节点的附加位移不超过 3 个世界单位；本次实际最大位移为纵向 2.39、横向 2.78，层级间距仍为 15/12。
- 固定种子 48 的修复前基准中，纵向有 4 个空间近线记录、38 个默认画面近线记录，横向分别为 4 和 31。共 77 条记录，涉及 23 个节点；同一节点/连线在不同检查中可重复出现。下表合并重复组合。
- 修复后两种布局的全部节点均与无关连线保持空间距离至少 1.2；默认画面同时检查节点球体外的留白。实际最小空间距离分别为 1.344 和 1.333。
- 专项测试覆盖 3 个随机种子、重启、往返切换、碰撞拾取位置、连线端点及位移上限，共 1,433 项通过。原有七组 689 项回归通过，总计 **2,122 项通过，0 项失败**。两种方向均通过实际视口点击解锁全部 32 个节点。
- 显卡渲染确认目标节点与所述连线分开；默认纵向/横向画面中，节点中心到该线的屏幕距离分别为 8.16/12.81 像素。截图和运行日志已保存。

## 扫描标准与范围

扫描空间中的点到线段距离，并检查两个默认相机视角下的投影距离。修复前清单使用空间 1.2 单位、画面约 0.9 单位投影半径作留白判定；最终 Godot 测试使用 0.85 单位投影半径作为验收下限，包含半径 0.6 的拾取区域和额外留白。

三维旋转可能让原本分开的对象在某个观察方向再次投影重叠；本次保证固定点位的空间避让及两个默认视角，未声称任意旋转角度下所有文字和连线均不相交。保留原有直线连线及前置科技关系。切换动画中继续逐帧保持连线端点同步。

复测命令：`Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tests/test_point_clearance.gd`。其余七组见 README。
